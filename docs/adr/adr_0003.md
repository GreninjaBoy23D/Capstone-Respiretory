## Context

The tool relies on taking the ROM file and extracting the samples from it. Functional Requirements 5-8 are the building blocks for the Sample Extraction and SoundFont Conversion. After being able to extract the samples, a user could be able to freely edit the samples in preparation for the SoundFont conversion (such as names, playback, conversion, and export).

## Consequences

**Positive**

- Allows a user to be able to extract the samples of a ROM file with ease.

**Negative**

- Samples extracted if not carefully by the tool could lead to corrupted sample data or no samples detected from the ROM.
